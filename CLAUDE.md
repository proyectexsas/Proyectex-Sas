# Proyectex SAS - Claude Instructions

## Stack
- Next.js 15 con App Router
- TypeScript
- Tailwind CSS
- framer-motion para animaciones

## Convenciones de código
- Componentes en `src/components/`, con nombre en PascalCase
- Páginas en `src/app/`
- No añadir comentarios salvo que la lógica sea no obvia
- Preferir `const` sobre `let`

## Skills disponibles

### /nuevo-componente
Crea un componente React en `src/components/` con TypeScript y Tailwind.
Pide el nombre y la descripción del componente antes de crearlo.

### /animacion
Añade animaciones con framer-motion al componente indicado.
Usa variantes para entradas, salidas y hover.

### /pagina
Crea una nueva página en `src/app/` con su layout básico y metadata.
